# BPMN Constructor — визуально-графический конструктор BPMN

Учебный ИТ-проект по дисциплине «Проектная деятельность в ИТ»
(Московский университет имени С. Ю. Витте, кафедра информационных систем).

**Назначение.** Веб-приложение для построения диаграмм бизнес-процессов
в нотации BPMN 2.0: размещение элементов (события, задачи, шлюзы) на холсте,
соединение их потоками управления, редактирование подписей, сохранение
диаграммы и экспорт в формат BPMN 2.0 XML.

**Технологии.** HTML5, CSS3, JavaScript (ES2020), SVG. Сторонние библиотеки
и сборка не требуются — приложение запускается открытием `src/index.html`
в браузере.

## Структура репозитория (по иерархической структуре работ)

| Каталог / файл | Этап ЖЦ проекта ИС | Содержание |
|---|---|---|
| `docs/01_initiation/` | 1. Инициация | Устав проекта, реестр заинтересованных сторон |
| `docs/02_analysis/` | 2. Анализ требований | Техническое задание (ГОСТ 19.201-78), глоссарий |
| `docs/03_design/` | 3. Проектирование | Архитектура, модель данных диаграммы, макеты интерфейса |
| `src/` | 4. Разработка | Исходный код приложения |
| `tests/` | 5. Тестирование | Тест-кейсы и автоматические проверки модели |
| `docs/05_deployment/` | 6. Внедрение и сопровождение | Инструкция по развёртыванию, план сопровождения |
| `docs/WBS.md` | — | Иерархическая структура работ (ИСР) проекта |

## Ветки репозитория

Ветки соответствуют этапам модели жизненного цикла проекта ИС:
`main` (стабильная версия) ← `develop` (интеграция) ←
`feature/analysis`, `feature/design`, `feature/development`,
`feature/testing`, `feature/deployment`. Категории пользователей и права
доступа описаны в `docs/WBS.md` и файле `.github/CODEOWNERS`.

## Быстрый старт

```bash
git clone git@github.com:<account>/bpmn-constructor.git
cd bpmn-constructor
open src/index.html        # macOS; в Windows — start src\index.html
```
