## 1. Обоснование проекта

Моделирование бизнес-процессов в нотации BPMN 2.0 является стандартом де-факто
при анализе и проектировании информационных систем. Существующие редакторы
(Camunda Modeler, bpmn.io, Bizagi Modeler) либо требуют установки, либо
избыточны для учебных задач. Требуется лёгкий браузерный инструмент, который
позволяет быстро построить диаграмму, проверить её на типовые ошибки и
сохранить в формате BPMN 2.0 XML, совместимом с промышленными системами.

## 2. Цели проекта

1. Разработать веб-приложение для построения BPMN-диаграмм без установки и
   серверной части.
2. Обеспечить экспорт диаграмм в формат BPMN 2.0 XML и JSON, импорт из JSON.
3. Организовать управление проектом по модели жизненного цикла ИС с
   использованием системы контроля версий Git и сервиса GitHub.

## 3. Границы проекта

**Входит:** элементы BPMN — начальное, конечное и промежуточное события,
задача, пользовательская задача, исключающий и параллельный шлюзы, поток
управления; редактирование подписей и документации элементов; проверка
модели; сохранение в localStorage; экспорт/импорт.

**Не входит:** пулы и дорожки, события сообщений и таймеров, подпроцессы,
исполнение процессов (BPMN-движок), многопользовательское редактирование.

## 4. Ключевые результаты

- Публичный репозиторий GitHub с исходным кодом и документацией.
- Работающее приложение (`src/index.html`).
- Комплект документов по этапам ЖЦ: устав, ТЗ, архитектура, тест-кейсы,
  инструкция по развёртыванию.

## 6. Риски

| Риск | Вероятность | Мера реагирования |
|---|---|---|
| Потеря локальных данных | Низкая | Регулярный push в удалённый репозиторий |
| Несовместимость экспорта с внешними редакторами | Средняя | Проверка XML в bpmn.io, следование спецификации OMG |
| Превышение сроков | Средняя | Фиксация границ проекта, приоритизация функций |
