# Глоссарий проекта

| Термин | Определение |
|---|---|
| BPMN (Business Process Model and Notation) | Графическая нотация моделирования бизнес-процессов, стандарт OMG, версия 2.0.2 |
| Событие (Event) | Элемент BPMN, обозначающий происшествие в ходе процесса: начальное, промежуточное, конечное |
| Задача (Task) | Атомарная работа в процессе; пользовательская задача выполняется человеком |
| Шлюз (Gateway) | Элемент ветвления/слияния потоков: исключающий (XOR, «×») и параллельный (AND, «+») |
| Поток управления (Sequence Flow) | Направленная связь, задающая порядок выполнения элементов |
| BPMNDI | Часть спецификации BPMN 2.0, описывающая графическое представление диаграммы (координаты и размеры фигур, точки излома потоков) |
| Диаграмма | Совокупность элементов и потоков одного процесса, объект редактирования в конструкторе |
| Холст (Canvas) | Область SVG, на которой размещаются элементы диаграммы |
| Палитра | Панель с перетаскиваемыми шаблонами элементов BPMN |
| Панель свойств | Панель редактирования атрибутов выделенного элемента (идентификатор, тип, название, документация) |
| Валидация модели | Автоматическая проверка диаграммы на типовые структурные ошибки |
| ЖЦ ИС | Жизненный цикл информационной системы — совокупность стадий от замысла до вывода из эксплуатации |
| ИСР (WBS) | Иерархическая структура работ — декомпозиция содержания проекта на пакеты работ |
| Репозиторий | Хранилище версий файлов проекта под управлением Git |
| Ветка (branch) | Независимая линия разработки в репозитории |
| Коммит (commit) | Зафиксированное состояние файлов репозитория с описанием изменений |
| Удалённый репозиторий (remote) | Копия репозитория на сервере (GitHub), используемая для синхронизации и совместной работы |
| Pull request | Запрос на слияние изменений ветки с обязательным ревью |
