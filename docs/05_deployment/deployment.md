# Инструкция по развёртыванию и сопровождению

## 1. Требования

- Любая ОС с современным браузером (Chrome 100+, Firefox 100+, Safari 15+).
- Git 2.30+ для получения исходного кода (необязательно — можно скачать
  архив репозитория).

## 2. Получение исходного кода

```bash
git clone git@github.com:Wraz178/bpmn-constructor.git
# или по HTTPS
git clone https://github.com/Wraz178/bpmn-constructor.git
cd bpmn-constructor
```

## 3. Запуск

Вариант А — локально из файла:

```bash
open src/index.html          # macOS
xdg-open src/index.html      # Linux
start src\index.html         # Windows
```

Вариант Б — через любой статический веб-сервер (например, для доступа с
других компьютеров сети):

```bash
python3 -m http.server 8000 --directory src
# приложение доступно по адресу http://localhost:8000/
```

Вариант В — публикация на GitHub Pages: Settings → Pages → Source: ветка
`main`, каталог `/src` (или корень с переадресацией).

## 4. Проверка после развёртывания

1. Открыть приложение — на холсте отображается демонстрационная диаграмма.
2. Перетащить элемент «Задача» на холст, соединить его с другими элементами.
3. Нажать «Экспорт BPMN XML» и открыть полученный файл `diagram.bpmn` в
   bpmn.io (https://demo.bpmn.io) — диаграмма должна отобразиться.
4. Открыть `tests/index.html` — все автоматические проверки отмечены «OK».

## 5. Сопровождение

| Процесс | Порядок |
|---|---|
| Приём дефектов | Issues репозитория GitHub, метки `bug`, `enhancement` |
| Исправления | Ветка `fix/<номер issue>` от `develop`, pull request, ревью, слияние |
| Релизы | Слияние `develop` → `main`, тег `vX.Y.Z`, запись в `CHANGELOG` (раздел Releases) |
| Резервное копирование | Удалённый репозиторий GitHub является резервной копией; локальные клоны у участников |

## 6. Направления развития

- Пулы и дорожки (участники процесса), события сообщений и таймеров.
- Ортогональная маршрутизация потоков с точками излома.
- Импорт BPMN 2.0 XML, созданного в других редакторах.
- Совместное редактирование в реальном времени.
