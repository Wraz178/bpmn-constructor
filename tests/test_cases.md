# Тест-кейсы и протокол испытаний

## 1. Автоматические проверки (tests/model.test.js)

Запуск в браузере: открыть `tests/index.html`. Запуск из командной строки
(macOS, JavaScriptCore):

```bash
jsc -e "load('src/model.js'); load('src/bpmn-export.js'); load('tests/model.test.js')"
```

| № | Проверка | Требование ТЗ | Ожидаемый результат |
|---|---|---|---|
| T01 | Добавление элемента | Ф1, Ф2 | Узел создан с размерами типа |
| T02 | Неизвестный тип элемента | 4.2 | Исключение |
| T03 | Создание потока | Ф4 | Поток создан |
| T04 | Петля запрещена | Ф4 | `null` |
| T05 | Поток из конечного события запрещён | Ф4 | `null` |
| T06 | Поток в начальное событие запрещён | Ф4 | `null` |
| T07 | Дублирующий поток не создаётся | Ф4 | `null`, один поток |
| T08 | Каскадное удаление потоков | Ф6 | Потоков 0 |
| T09 | Валидация пустой диаграммы | Ф7 | Предупреждение |
| T10 | Валидация без конечного события | Ф7 | Ошибка |
| T11 | Корректная диаграмма | Ф7 | «Ошибок не обнаружено» |
| T12 | Сериализация/десериализация JSON | Ф8, Ф10 | Данные совпадают |
| T13 | Некорректный JSON | 4.2 | Исключение |
| T14 | Экспорт BPMN 2.0 XML | Ф9 | Процесс, элементы, потоки, BPMNDI, экранирование |

## 2. Ручные (приёмочные) тест-кейсы

| № | Шаги | Ожидаемый результат | Требование |
|---|---|---|---|
| M01 | Открыть `src/index.html` | Отображается демонстрационная диаграмма из 6 элементов и 6 потоков | Ф1 |
| M02 | Перетащить «Задача» из палитры на холст | Элемент появился в точке отпускания, выделен, строка состояния сообщает об этом | Ф2 |
| M03 | Перетащить элемент мышью | Элемент перемещается с привязкой к сетке 10 px, потоки перестраиваются | Ф3 |
| M04 | Режим «Соединить»: щёлкнуть задачу, затем конечное событие | Создан поток со стрелкой | Ф4 |
| M05 | Режим «Соединить»: щёлкнуть конечное событие, затем задачу | Сообщение «Такой поток недопустим» | Ф4 |
| M06 | Двойной щелчок по элементу, ввести название | Подпись обновлена | Ф5 |
| M07 | Изменить название в панели свойств | Подпись на холсте обновляется по мере ввода | Ф5 |

| M09 | Удалить конечное событие | В блоке «Проверка модели» появляется ошибка «Отсутствует конечное событие» | Ф7 |
| M10 | «Сохранить», обновить страницу, «Загрузить» | Диаграмма восстановлена | Ф8 |
| M11 | «Экспорт BPMN XML», открыть файл в demo.bpmn.io | Диаграмма отображается | Ф9 |
| M12 | «Экспорт JSON», «Очистить», «Импорт JSON» | Диаграмма восстановлена из файла | Ф10 |
| M13 | Импортировать произвольный текстовый файл | Сообщение об ошибке, текущая диаграмма сохранена | 4.2 |
